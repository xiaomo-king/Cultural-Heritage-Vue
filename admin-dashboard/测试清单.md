# 七、总结：核心测试路径

```
建议优先测这 3 条核心链路：
```

### 链路 A：内容管理
```
后端启动 → 管理后台登录 → 新增非遗项目 → 编辑非遗项目 → 删除非遗项目
```

### 链路 B：电商运营
```
小程序注册 → 添加购物车 → 下单支付 → 管理后台查看订单 → 发货操作
```

### 链路 C：用户互动
```
小程序发布打卡 → 浏览打卡 → 点赞/评论 → 管理后台管理打卡和评论
```
